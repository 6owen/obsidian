# AI 辅助内容与产品工作流

## 核心模式

原始笔记中的 AI 使用不是单纯“问答”，而是把复杂工作拆成可重复的流水线：

输入材料 → AI 分类/提取 → 人工或程序筛选 → AI 结构化生成 → 人工审核 → 软件化交付。

## 例子

- 小说：创意 → 人物 → 大纲 → 分场景正文 → 人工润色与排版。
- 探店视频：字幕/音频 → 关键词筛选 → 关键帧 OCR → AI 综合店名。
- 网页设计：需求与参考图 → 设计系统/token/spec → Codex 实现 → 视觉复核。
- 视觉内容：固定风格与构图约束 → 分镜或单图 Prompt → 图像/视频模型生成。
- 知识库：检索 → 判断是否充分 → 二次检索/跨来源对比 → 带引用回答。

## 个人倾向（基于多篇笔记的归纳）

关注点从“会不会调用模型”转向“能否理解模型差异、固定质量约束、把流程产品化并降低使用门槛”。这与[[obsidian/随笔/前端 AI]]中的表述一致。
