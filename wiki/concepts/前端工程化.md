# 前端工程化

## 主要组成

- 代码质量：ESLint、定制规则、自动修复、编辑器集成。
- 提交约束：Git hooks、lint-staged、提交信息校验。
- 版本控制：revert、reset、rebase、checkout、stash 的不同使用边界。
- 构建与发布：Vite/Rollup/tsup、类型声明、NPM 发包、自定义模块引用。
- 测试：Cypress 浏览器端 E2E 测试。
- 环境一致性：VS Code 配置、ignore 文件、NVM/npm、Docker 和部署脚本。

## 原始笔记体现的原则

- 只检查暂存区能缩短 pre-commit 的反馈时间。
- 撤销历史时，`revert` 通过新增提交保留历史；`reset` 和强推会改写历史，风险不同。
- TypeScript 库发布时需要让 `package.json` 正确指向声明文件。
- 自定义 ESLint 插件应同时包含规则实现、元数据、测试和消费配置。
