# 个人技术能力图谱

> [!note] AI 归纳
> 本页根据笔记数量、完整度和项目线索归纳，不等同于经过外部验证的熟练度评级。

## 主干能力

### 前端与 JavaScript

- JavaScript 对象模型、作用域/闭包、`this`、异步和事件循环。
- React、TypeScript、CSS/Tailwind、浏览器 API 和交互动效。
- Git、ESLint、Git hooks、测试、构建、NPM 包与项目模板。

### 图形、地图与可视化

- WebGL/Shader/GLSL、UV、纹理、Three.js。
- GIS 基础、GDAL 瓦片、QGIS 数据处理。
- Blender 高程置换和三维地形渲染。
- Cesium/WebGIS 的场景、地图、模型、要素和特效清单。

### 自动化与部署

- Node.js 文件脚本、油猴脚本。
- ADB/Termux/Python 设备自动化。
- WSL、Docker、PM2、NVM/npm 和基础服务部署。

### AI 应用

- 结构化提示词、视觉/视频生成、角色化写作。
- OCR + 字幕 + AI 的信息提取流程。
- 从设计系统/spec 到 Codex 实现的软件生产链路设想。
- RAG/Agentic RAG 与个人知识库方向。

## 知识形态

- 强项：能把具体问题拆成步骤，记录可执行命令和代码；擅长用类比建立概念连接。
- 当前短板：不少项目停在提纲或实验阶段，缺少最终交付物、测试结果、指标和复盘。
- 潜在差异化：前端工程能力与 Shader/WebGIS/AI 工作流交叉，而不是单一页面开发。
