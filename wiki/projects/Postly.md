# Postly

## 项目构想

一个面向个人内容的管理与发布系统。

## 已记录范围

- 管理端：文章增删改查。
- 接入：通过 MCP 支持 VS Code、Trae 等编辑个人文档。
- 服务端：提供标准 API。
- 内容：个人简历和信息等。
- 前端：后端 API 固定后，除预置模板外允许自行实现不同样式。

## 当前缺口

原始笔记只有提纲，尚缺目标用户、内容模型、权限、发布渠道、同步冲突策略和最小可用版本范围。
