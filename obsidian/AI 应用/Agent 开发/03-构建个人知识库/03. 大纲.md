## 2. 这一部分的核心问题

### 2.1 为什么“有资料”不等于“有知识库”

因为大量资料通常只是分散存在于笔记、代码、文档、网页摘录和项目记录里。它们对人来说也许还能靠经验和搜索勉强使用，但对 Agent 来说，没有边界、结构、入口、来源和权限时，就很难稳定调用。

### 2.2 个人知识系统到底要解决什么

这一部分要解决的不是“让模型记住一切”，而是：

- 让资料可被定位
- 让结论可回到原始来源
- 让知识可被增量维护
- 让 Agent 知道先查哪里，再查哪里
- 让输出带证据，而不是只像“说得很像”

## 4. 这部分最终要留下什么

读完 Part 03，你应该至少能落下一套最小个人知识系统：

- 原始资料继续保留在原目录
- 有可检索的索引层
- 有可追溯的 Wiki 层
- 有受控的记忆层
- 有明确的 Agent 使用入口

这样 Part 04 再往上继续讲个人 Agent 时，知识、记忆、工具和工作流才有了真正可落地的基础。
