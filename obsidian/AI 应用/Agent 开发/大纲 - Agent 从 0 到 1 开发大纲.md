## 总体路线

| 阶段 | 能力增量 | 关键抽象 | 验证重点 |
| --- | --- | --- | --- |
| M0 | 调用模型 | HTTP API、Messages | 请求、响应、错误和费用可见 |
| M1 | 调用工具并循环执行 | Tool Calling、Agent Loop | 能选对工具并正常结束 |
| M2 | 检索外部知识 | File Search、RAG | 能找对资料并给出引用 |
| M3 | 自主规划检索 | Agentic Search、Agentic RAG | 能拆解问题并判断证据是否充分 |
| M4 | 使用个人资料回答 | Knowledge Base、LLM Wiki | 能从结论追溯到原始来源 |
| M5 | 扩展个人 Agent | BYOK、Memory、Skills、MCP | 能安全组合模型、记忆和工具 |
| M6 | 编排复杂任务 | Workflow、Workspace、Supervisor | 能恢复、分工、汇总并控制成本 |
| M7 | 产品化 | Trace、Eval、Security、Deploy | 可观测、可评测、可恢复 |

### 本部分需要讲清

| 问题 | 结论方向 |
| --- | --- |
| 大模型是不是 Agent？ | 不是。模型是推理与生成核心，Agent 是围绕模型建立的执行系统。 |
| Tool Calling 是不是工具执行？ | 不是。模型提出调用意图，程序负责验证和执行。 |
| 为什么需要 Agent Loop？ | 让模型能够根据工具结果继续决策，直到完成或触发终止条件。 |
| 所有任务都需要 Agent 吗？ | 不需要。固定、可预测的任务优先使用普通代码或 Workflow。 |

### 核心概念对照

| 概念 | 主要作用 | 典型内容 | 核心要求 |
| --- | --- | --- | --- |
| File Search | 从已有文件中定位材料 | Markdown、代码、PDF、日志 | 找得准、能回到原文件 |
| RAG | 检索材料后生成回答 | 文档 Chunk 与 Metadata | 召回、排序、引用 |
| Agentic Search | 由 Agent 规划和执行搜索 | 多来源、多查询、多轮结果 | 搜索策略与停止条件 |
| Agentic RAG | 由 Agent 动态控制 RAG 链路 | 检索工具、证据判断、多跳查询 | 可控循环与证据充分性 |
| Knowledge Base | 存储可复用知识 | 文档、数据库、网页、代码 | 可检索、可更新、权限清晰 |
| LLM Wiki | 组织可连接、可追溯的派生知识 | 概念、实体、项目、决定、综合 | 双链、来源、增量维护 |
| Memory | 保留持续状态 | 偏好、历史选择、任务进度 | 写入规则、作用域、可遗忘 |
| Context | 本次调用实际看到的内容 | 消息、检索片段、工具结果 | 相关、精简、不过期 |

### 知识库的建议分层

| 层 | 保存内容 | 默认写入者 | 更新方式 |
| --- | --- | --- | --- |
| Raw | 原始笔记、文件、网页、代码 | 用户或原始系统 | 保留原文 |
| Index | 文件索引、全文索引、向量与 Metadata | 程序 | 自动重建或增量更新 |

| Memory | 用户偏好、任务状态和历史选择 | Agent 按规则写入 | 可查看、修正和删除 |

### 关键能力的职责边界

| 能力 | 适合负责 | 不适合负责 |
| --- | --- | --- |
| Model | 理解、生成、判断和规划 | 直接执行真实世界操作 |
| Tool | 有边界的查询或操作 | 自主决定整个任务流程 |
| Skill | 可复用的方法、规范和领域经验 | 保存运行状态 |
| MCP | 统一连接外部工具与数据 | 替代业务权限系统 |
| Workflow | 确定性步骤、分支、重试和审批 | 完全开放式推理 |
| Memory | 保存需要跨任务延续的信息 | 充当全部知识库 |
| Workspace | 隔离任务文件、产物和运行状态 | 代替长期知识治理 |
| Supervisor | 拆解、分派、汇总和验收 | 无限制地继续委派 |

## 端到端案例主流程

| Step | 行为 | 使用能力 | 检查点 |
| --- | --- | --- | --- |
| 1 | 接收复杂任务 | Chat/API | 目标和边界是否明确 |
| 2 | 判断是否需要检索 | Agent | 是否可以直接回答 |
| 3 | 查询个人知识 | Wiki、File Search、RAG | 是否找到原始来源 |
| 4 | 补充外部信息 | Agentic Search | 来源是否可信、是否过期 |
| 5 | 拆解并执行子任务 | Supervisor、Skills、MCP | 分工是否清晰、权限是否足够 |
| 6 | 保存中间产物 | Workspace、Workflow | 是否可恢复、是否相互隔离 |
| 7 | 汇总与证据核验 | Agentic RAG | 证据是否充分、是否存在冲突 |
| 8 | 执行高风险操作 | Human-in-the-loop | 是否获得用户确认 |
| 9 | 输出并记录 | Trace、Eval | 引用、费用和结果是否完整 |
| 10 | 回归与复盘 | Evaluation | 修改后是否改善且无退化 |
