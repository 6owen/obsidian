## 1. 周五美股暴跌，qqq 跌了 4.8%，其余所有美股全部暴跌

周四的时候，博通财报发出来，业绩不行，盘前也就是亚洲这边日韩给整的活吧，跌了很多。开盘之后，周四晚上 qqq 先暴跌了一会，然后就直线上升。

就我个人的经验，我是看到周四虽然就前面十几分钟跌，后面拉上来了，但是资金流入流出量对比，大单中单小单，全部都是流出比较多，流入很少。

所以我感觉有点不太对劲，但是说也说不上来，我就没开单，静静的观察。

等到了周五，盘前还是跌，盘前直接跌了 1%，在平常这种情况可不多见，头一天盘前大跌，盘中拉回来。第二天盘前还是大跌，到晚上盘中的时候，我开了一小单，显示跌，后面拉上来了，本来是准备逃顶，但是后面又想拿过夜，多赚几块钱。

后面突然有个群友说，暴跌了，赶紧溜，我一听，就赶紧平了单，最后就亏个手续费，但是那个群友却没有走。

然后就看着 qqq 暴跌，所有的美股都暴跌，感觉自己好像躲过了一劫一样，虽然亏了手续费，但是感觉自己赚了很多钱。

我本来就有点感觉不太对劲，但是说不上来，最后还是那个群友说了，我就直接溜了。

其他人感觉虽然设置了止损，但是还是亏了 1 个月的收益吧。

有可能是 SpaceX 上市，钱都提出来，准备给 SpaceX 买单了。

但是具体好像我也分析不出来什么，也算是个经验了，虽然我也没亏啥，但躲了一劫，哈哈昂。

另外又买了一单 270 的迈威尔，从前天买了两 300 的迈威尔，到今天亏了 90 刀了，今天补一股吧，反正钱也不多，放着吧。

## 2. 嘉信账户，盈立账户都入金好了

之前开通了嘉信账户，盈立账户，之前一直没有入金，今天终于入金了。

感觉汇丰入金的有点没那么方便，虽然我添加了嘉信的公户作为汇款人，然后备注里面填上我的账户信息，第一次入金成功了。但是我第一次就入金了一点钱，后面又准备入金一笔，但是发现我的账户信息没有了，还要再去官网上找，那就没有继续冲了。

感觉可以先盈立用一下。盈立新加坡，是周大福投资的，感觉挺奇怪的，一方面是国人班底，另一方面软件感觉有点草台，还有一方面是监管。不过界面还可以吧，准备这周用一下。
嘉信的账户时不时动一下，准备买买美股吧，期权感觉我还没用会这个软件。

## 3. pi 的编排有了进展，但是发现 mastra 更好用

之前 pi 的编排一直没有什么进展，很多事情要自己做，更像组装乐高。
不过这周有很大的进展，都编排好了，就是每个 agent 单独的 workspace 了，感觉很不错。

不过到周五了，我自己体验了一下 mastra ，之前总是在 x 上刷到，但是我感觉没有手动自己编排好用吧？
毕竟之前用了 vercel ai sdk 的，也是这种东西，但是还没有从 0 开始的 pi 好用，就一直没有体验。

但是这次我一体验，感觉确实好用。别的也不多说，只看文档就知道好用了。

## 4. 博宇要高考了

今年博宇高三，7,8,9 三天高考。我昨天问他，第一天的考试怎么样，他是很有自信，语文就不多说了，大家都这个样，看运气吧。
数学在下午，我看微博热搜上显示的，今年数学也是比较难，我就问他，他很有自信，感觉考的不错。

唯一的小插曲就是考场上，家里在下雨，考场上没有开空调，开了风扇，但是一直在吱吱作响，完全影响了他的考试心态。然后他找老师说了，关了风扇。
还说今天一到考场，就要跟监考老师说一下，今天不能开风扇，他觉得监考老师应该没有问题吧，虽然今天换了新的老师。

但是后天天热了，不知道能不能开空调，而不是开风扇，不然真的很影响人。

希望他这两天能发挥好，考个好成绩。
