## 1. 学习 pi agent 开发

最近还是想一下金融的分析，准备先弄一些大的方向，比如新闻，社媒，市场行情，然后 AI 分析预测一下未来的走势。 
虽然我知道，市场其实并不一定跟随消息走，反映到市场上，可能是消息都已经消化完了。但是还是想有根据的有步骤的去操作，完全平主观感觉盲目买卖，感觉没有脚踏实地，心里有点空。

之前都是使用 Vercel AI SDK 去接入模型，封装的。虽然接入简单，也挺好用，但是发现后面的步骤都需要自己一步步实现，比如 message 的渲染，倒是提供了 AI Element 组件，可 AI 使用起来没有那么顺畅，需要封装一套自己的格式。

然后看到了 [PI](pi.dev) 发现有很多 packages ，其实在之前开发之前就在选择，是使用 pi-mono 还是 vercel ai sdk ，最后选择了 ai sdk ，因为背靠 vercel ，然后推出来不少配套的组件库。
但使用 codex 开发起来，并没有想象中的那么顺畅。虽然看文档，有 memory，也有 provider ，也有 message 渲染，和 subagent 的。 但是使用起来没有那么顺，然后又看到 harness 的思路应该就是很简单的执行，看 Hermes Agent 的源码也是不绕圈圈的实现。

最后算了，全部改成 pi-mono 吧，还是社区的力量好用。

准备后面，虽然能明白 ai 根据市场新闻消息分析不那么靠得住，但是还是做个参考吧。
