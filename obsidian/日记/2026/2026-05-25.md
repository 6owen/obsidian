感到深深挫败感的一周

> 1. 美股未开单
> 2. 国内限制富途老户长桥

> 4. 浏览器插件，以及构建自己知识库

## 1. 美股未开单

这一周就是完全陷入慌乱之中，虽然最后每次过后，看到结果和过程中的 K 线图，只需要无脑执行 bull sell put spread ，不需要任何分析，就可以成功。
但是每天还都是非常纠结，没有执行计划，没有执行纪律，感觉顶多就是堵一个方向。

后面看到别人给出的一个复盘：

> 复盘下来，最致命、反复出现的问题集中在四点：
> 卖飞：买点其实不差，但波动一剧烈就拿不住，小赚就跑，后面拉升只能眼睁睁看着，不敢再接回；
> 方向错硬扛：明明判断已经出错，却总想等反弹回本再走，结果越扛越被动、亏损越放越大；
> 乱做差价：在震荡行情里频繁刷小波段，试图赚点差价，最后利润基本都交给了手续费；
> 买点踩坑：总买在半山腰，一回落就扛不住，最后割在相对低点。

> 主要以 QQQ 成交量、KDJ、MACD 三个指标来判断方向与进场时机，也慢慢总结了几条自用的基础规则：
> 盘前必看数据：纳指期货走势、QQQ 盘前报价，以及是否有 CPI、失业金等重大数据发布；
> 提前标记关键位：前一日低点作为支撑，前一日高点作为阻力；
> 定方向：期货强势偏向 Call，期货弱势偏向 Put，震荡行情直接放弃；
> 指标过滤：RSI 超买（>75）等回调到 60-70 区间再考虑进场，超卖（<25）等反弹到 30-40 区间再出手，尽量避开极端行情。

> 买 QQQ 0DTE 关键问题 ：怎么判断方向？怎么找最佳买入点？卖出信号是什么？怎么才能抗住波动时期不被甩下车？出场纪律怎么定？

总结到最后，其实我发现，不需要复杂的分析，因为每天只开一单，所以其实就是堵一个方向，要么赌对，要么赌错。
没有那么多弯弯绕绕的分析，不过可以从这些分析中，提炼出一些纪律性的东西来，或者一些基础的知识来。

## 2. 国内限制富途老户长桥

上周国内发了新闻，处罚富途老虎长桥，禁止国内人员开通美股账号，炒美股，以后就可能面临着 CRS 和法律监管了。

富途也因为这个消息，盘前股价一下子从 120 多跌到了 70 多，我看到之后，想抄底两股，但又没有执行，后面开盘又涨回 90 多了。唉，没有执行纪律，就永远是这样看到消息，有这个想法，但执行不了。

盘前这个消息出来之前，就突然爆发很多 put ，因为距离现价太远，很多 put 也成交了。这一个消息，赚发了。

## 3. agent 开发受阻

之前使用的 pi 进行开发 agent ，非常好用，就像搭积木一样，拖拖拉拉就可以搭建一个 agent 出来。
但是最近我打算做一个 multi agent 的系统，底层单 agent 还是 pi ，但是上层需要每个角色对应一个 pi ，这对于 pi 来说，也很简单。但是这里的编排就需要我自己来做了。
而且还面临 agent 直接的通信问题，我当然是准备很简单的实现，接力棒模式，将每个输入输出往下传。但是实现起来，发现可能还是耗费一点心力。

## 4. 浏览器插件，以及构建自己知识库

上面受阻了之后，我又拾起来了之前想做的浏览器插件，之前做到一半就停止了，因为总是感觉不好看，没有适配自己的审美。 但是上面 agent 给我的想法，自己的知识库，可以很好的和浏览器插件结合起来。
然后又接着做了，可以还是感觉没那么好看，就是有点好看，但是总达不到完美，贴合自己的审美的程度。唉，感觉自己是个完美主义者，想要做出一个完美的东西来，但是又没有那个能力来实现，所以就一直停滞不前。

## 5. 生活方面

这个上面倒是没有什么特别的事情发生，不过上面一系列给我很挫败的感觉，感觉做什么都是半途而废。觉得自己好失败。
周五春春跟我说，她朋友小田准备年底备孕了，然后又故意提到，说她婆婆全包，她只管生娃就好了。
我也就接着，我知道从小田结婚那时候，就感觉像准备生娃了。
后面她也没说话了，我也没说话了。

其实我一直也不想生娃，也不光是单纯不想生，一个是感觉夫妻生活不和谐，二是感觉夫妻理念也不合适，三是感觉自己也没有那个能力来养育一个孩子，四是感觉生了孩子之后，可能会对夫妻关系造成更大的伤害。
而且我家里也没有钱说帮助我养育孩子，她也总是这样提，自己也没说付出什么。不过可能女性付出身体上的痛苦，就是天大的了吧。

所以我也就一直没有说什么，感觉自己也没有什么资格说什么。夫妻生活不和谐，以前还想着去解决，但是就一直仿佛是我低她一等了，面对趾高气扬的态度，我现在也不打算去解决了，就这样吧。
