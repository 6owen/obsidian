> 一旦我所属的文件夹有所变化，请更新我。

1. 新开一个 GItHub 仓库，下载下来
2. Obsidian 打开仓库文件夹
3. 找到左下角的“设置”  ->弹窗面板左侧的第三方插件“关闭安全模式” -> 搜索下载插件“obsidian-git” -> 还是这个弹窗面板，找到打开最底部的刚才下载安装的 "obsidian-git" -> 开启插件
4. ctrl + p 打开命令面板，输入 obsidian git open source control view ，点击打开
5. 面板右侧弹出 git 面板，跟 vscode 一样的提交管理


日记与周记正文存放在 `日记/<年份>/`，对应素材存放在 `日记/assets/`；年份目录中的正文和封面使用 `../assets/文件名` 引用。

| 目录 | 地位 | 功能 |
| --- | --- | --- |
| `日记/` | 原始笔记 | 按年份维护日记与周记，用 publish 控制博客发布 |
| `博客/` | 原始笔记 | 从 Arvin 迁入的技术文章，当前 publish: false |
| `assets/` | 默认附件位置 | Obsidian 粘贴、拖入新附件时的全局默认目录 |

博客文章保存在 `博客/`，素材保存在 `博客/assets/`，通过 `assets/文件名` 引用；迁入的 22 篇博客均不发布到 Postly。
